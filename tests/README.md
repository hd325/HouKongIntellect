# 回歸測試與瀏覽器檢查

在專案根目錄、Python 3.12 虛擬環境中執行：

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests
```

Windows PowerShell 未啟用虛擬環境時，將 `python` 改為 `.\.venv\Scripts\python.exe`。

## 自動測試範圍

- 文件權限、原文預覽與下載，以及靜態資源的允許清單。
- 上傳分析的暫存隔離、OCR 進度、人工欄位、5 字備註上限和重複資料提示。
- 教師審核、發布與退回，待審原件隔離，以及儲存失敗的回復處理。
- 文件目錄、索引可見範圍、檢索回退和文件引用。
- 出題參數、模型 JSON、原文依據與來源頁，以及檢索統計。

測試使用合成帳號、臨時文件、模擬模型和模擬向量庫，不需要雲端密鑰。請在乾淨的公開版環境執行；測試案例會各自隔離需要寫入的記錄，應用匯入時仍會建立配置的資料目錄。

## 瀏覽器測試資料

下列工具以合成文件和帳號展示正式前端，停用模型、OCR 和向量寫入；先完成核心與開發依賴安裝。

```bash
python tests/upload_browser_harness.py
```

或：

```bash
python tests/review_browser_harness.py
```

根據終端列印的地址開啟頁面，同時只啟動一個工具。這些工具使用臨時資料，不是正式應用的帳號管理介面。Windows 未啟用虛擬環境時使用 `.\.venv\Scripts\python.exe`。

## 人工檢查

1. 登入後選擇文件，檢查 PDF、圖片、Word／文字預覽，以及來源頁導航。
2. 選擇文件上傳，核對「AI 建議 → 人工修改 → 確認上傳」流程；嘗試空備註、5 字及超過 5 字，確認進度和結果。
3. 使用學生帳號送審共享資料，確認待審資料不出現在正式文件列表及檢索；使用教師帳號通過或退回，再核對可見範圍。
4. 配置模型後生成練習，檢查答案顯示、來源依據和列印；文件素材取自前 3,000 字，前部為目錄時需額外核對題目。
5. 檢查 Esc、Tab 焦點與彈窗關閉，並在窄螢幕、淺色及深色模式核對排版。
6. 重啟應用，確認本機帳號、對話、已發布資料與待審記錄能恢復。

原頁預覽需要對應的上傳原件。僅有提取文字時可提供文字依據，但無法還原 PDF 頁面圖像。
